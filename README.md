## 🚀 Projets principaux

### 🏥 Electronic Health Record (EHR) System
Développement d’un système complet de gestion de dossiers médicaux :
- Backend en **Flask**
- Authentification sécurisée avec **JWT**
- Base de données **SQLite**
- Modules pour : gestion des utilisateurs, des patients et des rendez-vous
- Intégration de **Machine Learning** et **Deep Learning** pour l'analyse de données médicales

🔗 [Voir le dépôt](https://github.com/mayssal/medical_db)

---

### 🐾 Animal Health App
Application de gestion de santé pour animaux :
- Interface intuitive
- Suivi des symptômes, traitements, visites vétérinaires
- Architecture modulaire avec bonne séparation des responsabilités

---

### ✅ Task Manager
Gestionnaire de tâches avec :
- Priorisation des tâches
- Filtres et organisation claire
- Notification et marquage d’état

---

### 🤖 Robot suiveur de ligne (Arduino)
Robot autonome réalisé avec :
- **Arduino Uno**, 4 moteurs, 3 capteurs infrarouges
- Algorithme de suivi dynamique de ligne
- Code optimisé pour la précision du suivi

🔗 [Voir le dépôt](https://github.com/mayssal/suiveur-de-ligne)
